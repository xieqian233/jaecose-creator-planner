# 简可思达人排期协作版

保留原版看板的评级、创作方向、可发布档期筛选、时间分布和测试结论功能。达人资料从原飞书表读取，排期编辑保存到独立协作表。

## 数据约定

- 原达人筛选表只读；服务器拒绝对原表发送写入请求。
- 更新达人资料时保留拟发布日期、制作状态、测试假设、备注、结论及本轮测试标记。
- 档期表示可发布日期，拟发布日期单独维护；两者不同需要与达人确认。
- 打开网页时同步，保持网页开启时每五分钟刷新，也可手动同步。关闭网页期间不自动运行。
- 保存前核对排期更新时间，发现已过期的编辑会拒绝保存并提示刷新；飞书不提供事务式比较更新，因此不承诺同时提交完全原子化。
- 原表移除或取消建联的达人不删除历史协作记录，也不继续开放排期编辑。
- 页面和接口需要站点登录；初始访问范围保持私有。团队访问需另外配置指定成员。

## 飞书应用

应用：简可思达人排期同步。所需五项应用身份权限：`base:record:retrieve`、`base:record:create`、`base:record:update`、`base:field:read`、`base:field:create`。

原多维表格添加该应用为阅读权限；协作多维表格添加为编辑权限。服务器运行配置的键名见 `.env.example`。应用密钥必须使用托管平台的密钥设置，不得写入代码、浏览器或 GitHub。

协作表新增十三个字段，包含来源记录ID、来源方向快照、排期主方向、拟发布日期、制作状态、测试结论状态、测试假设、实际结果与下一步、排期备注、本轮测试、最近编辑人、排期更新时间、来源同步时间。

## 检查与发布

准备前端：`node scripts/prepare-planner.mjs`。

运行同步和保存检查：`node --test tests/feishu.test.mjs`。

使用 Sites 官方工作流构建、推送源代码和发布。GitHub 仓库仅同步代码，不提交达人数据、报价、导出表格或任何凭证。托管站点的项目标识保存在 `.openai/hosting.json`，更新时复用同一标识。

尚未完成真实连接时，网页显示连接待完成，不展示演示名单或假保存成功信息。
