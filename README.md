# 简可思达人排期工具

首页为单文件 `index.html`，通过 GitHub Pages 发布。仓库公开，页面中不内置达人名单、报价、排期备注或飞书密钥。

打开网页后，导入原本地网页导出的 JSON 备份，或飞书 CSV，即可按 A／A-／B／C、创作方向和可发布档期筛选，查看时间分布，填写拟发布日期和测试结论，并导出排期及完整备份。

数据和修改保存在当前浏览器。分享网址不会自动分享已经导入的数据和修改；同事需要导入备份。此版本不自动读取或写入飞书。

GitHub Pages 使用 main 分支的根目录。后续更新网页时替换根目录 `index.html`。

## 自动同步协作版

`app`、`frontend`、`lib` 等目录保留服务器协作版代码，`planner-source.zip` 为其初始代码包。此功能尚未部署，需另行配置运行服务、飞书应用密钥及原表阅读授权；GitHub Pages 本身不运行这些接口。密钥和达人导出文件不得提交到公开仓库。
